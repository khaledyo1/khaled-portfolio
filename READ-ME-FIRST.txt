اقرأني أولاً — تشغيل الموقع

إذا ظهر الموقع مثل صفحة بيضاء وروابط زرقاء، فهذا يعني أن CSS والصور لم تُحمّل.

الطريقة الصحيحة:
1) اضغط يمين على ملف ZIP.
2) اختر Extract All / فك الضغط.
3) افتح المجلد الناتج كامل.
4) افتح index.html.

ممنوع:
- لا تفتح index.html من داخل ملف ZIP مباشرة.
- لا تنقل index.html وحده إلى مكان ثاني.
- لازم تظل المجلدات التالية بجانب index.html:
  css
  js
  assets

تشغيل أفضل:
افتح Terminal داخل المجلد واكتب:
python -m http.server 5500

ثم افتح:
http://localhost:5500
