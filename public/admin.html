لوحة تعديل البورتفوليو

من هنا تقدر تغيّر الصورة الرئيسية، بيانات التواصل، روابط السوشيال ميديا، وتضيف/تحذف/تعدل المشاريع. الحفظ النهائي يحتاج إعداد متغيرات GitHub داخل Vercel مرة واحدة فقط.

فتح الموقع
مهم: زر “معاينة محلية” يطبق التغييرات على جهازك فقط. زر “حفظ ونشر” يحدّث ملف public/content/site-content.json داخل GitHub ويعمل Redeploy تلقائي عبر Vercel إذا ضبطت المتغيرات المطلوبة.

الصورة والواجهة الرئيسية

عدّل النص الأساسي والصورة التي تظهر في الصفحة الرئيسية.

التواصل والسوشيال ميديا

غيّر الإيميل، واتساب، وروابط المنصات الظاهرة في الهيدر والفوتر وصفحة التواصل.

المشاريع

أضف مشروعاً، احذف مشروعاً، غيّر التصنيف، الصورة، النصوص، والروابط.

الحفظ والنشر

استخدم المعاينة قبل النشر. للحفظ النهائي أدخل كلمة مرور الإدارة التي ستضعها في Vercel.

إذا لم تضبط GitHub Token داخل Vercel، سيعمل التصدير والمعاينة فقط. هذه طبقة أمان مقصودة حتى لا يوجد Token مكشوف في المتصفح.
