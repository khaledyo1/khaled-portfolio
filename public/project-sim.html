GENERAL CONCEPT

Project overview

SIMLink is a telecom landing page concept for SIM-related services such as new SIM orders, replacement, number porting, eSIM activation, delivery, coverage checking, and plan comparison.

PROBLEM

The problem this project addresses

SIM services can be confusing because the user may not know which service to choose, what documents are needed, how long delivery takes, or how to compare available plans.

SOLUTION

How the solution was structured

The solution was to design a guided landing page that explains each SIM service through simple cards, shows the steps clearly, highlights plan options, and gives the user a direct path to start the request.

VALUE

What this case study proves

This project proves the ability to simplify a technical service and present it in a customer-friendly landing page that supports quick decisions.

TARGET USERS

Who this project is designed for

  • Telecom companies
  • SIM service apps
  • Users who need new or replacement SIMs
  • eSIM service providers
  • Customers comparing mobile plans

BUILD PROCESS

How I approached the project

  1. Separated service types so users can identify what they need quickly.
  2. Created comparison areas for plans and actions.
  3. Used concise copy for technical telecom steps.
  4. Designed the layout to work cleanly on small screens.
